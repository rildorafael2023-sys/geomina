GeoMina — aplicativo local de gestão de dados geológicos
=========================================================

O aplicativo roda somente neste computador. Ele não usa internet e não aceita
conexões de outros computadores (atende apenas em 127.0.0.1).

INSTALAÇÃO
- Dê dois cliques em GeoMina-Setup-<versão>.exe e siga as telas.
  NÃO é preciso instalar Python nem nada mais: tudo vem dentro do instalador.
  Não pede senha de administrador (instala só para o seu usuário do Windows).
- O Windows pode mostrar "O Windows protegeu o computador" (instalador sem
  assinatura digital): clique em "Mais informações" e depois "Executar assim mesmo".
- São criados atalhos na área de trabalho e no menu Iniciar (pasta GeoMina).

ATUALIZAÇÃO
- Feche o GeoMina e rode o instalador da versão nova. Os dados são mantidos e o
  banco recebe backup automático antes de qualquer atualização.
- Quem usava a versão antiga (instalar.bat com Python): basta rodar o instalador
  novo. Os dados são os mesmos (%LOCALAPPDATA%\GeoMina). A pasta antiga pode ser
  apagada depois de conferir que tudo abriu.

USO
- Abra pelo ícone "GeoMina". Ele abre em janela própria (usa o Microsoft Edge já
  existente no Windows). Ao fechar a janela, o programa se encerra sozinho.
- No primeiro acesso, crie o usuário administrador.
- "GeoMina (diagnóstico)", no menu Iniciar, abre mostrando as mensagens numa janela
  preta. Use se algo der errado e envie a mensagem ao suporte.
- Registro de funcionamento: %LOCALAPPDATA%\GeoMina\logs\geomina.log

ONDE FICAM OS DADOS
  %LOCALAPPDATA%\GeoMina   (banco geomina.db, arquivos originais e backups)
  Atalho: menu Iniciar > GeoMina > "Pasta de dados e backups".

BACKUP
- Automático: diário (só o banco, guarda 14) e semanal completo (com fotos,
  croquis e laudos, guarda 4), cada um testado com uma restauração simulada.
- Configure em Backup > "Segunda pasta para cópia automática" um pendrive, HD
  externo ou pasta da rede: cada backup automático é copiado para lá.
- Backup completo manual e restauração: menu Backup.

DESINSTALAR
  Menu Iniciar > GeoMina > "Desinstalar o GeoMina" (ou Configurações > Aplicativos).
  Os dados em %LOCALAPPDATA%\GeoMina NÃO são apagados.
